# hardware/3d_models

SafeNest 외함의 3D 프린팅용 STL 과 설계 사양이다. 단위는 모두 **mm**.

## 파일

| 파일 | 역할 |
|---|---|
| `housing_body.stl` | 센서 노드 외함 본체 (직육면체, 137×80×60) |
| `sliding_back_panel.stl` | 센서 노드 슬라이딩 후면 패널 |
| `trapezoid_housing_body.stl` | LCD·부저 하우징 본체 (사다리꼴, 240 W × 140 H) |
| `trapezoid_T_back_panel.stl` | LCD·부저 하우징 T형 후면 패널 (환기 슬롯 포함) |
| [`설계_사양.txt`](설계_사양.txt) | 센서 노드 외함 치수·개구부·환기구·출력 조건 |
| [`사다리꼴_하우징_설계사양.txt`](사다리꼴_하우징_설계사양.txt) | LCD·부저 하우징 치수·부저 그릴·음각·환기 사양 |

렌더 이미지는 [`final-report/assets/`](../../final-report/assets/) 의 `3d_*.png` 에 있다.

## 센서 개구부 (센서 노드 외함)

| 개구부 | 치수 | 대응 센서 |
|---|---|---|
| PIR | 24 × 24 | PIR 모션 센서 |
| Thermal | 직경 11.85 | MI48xx 열화상 |
| CO₂ | 13 × 26 (직각 모서리) | MH-Z19B |
| mmWave | 36 × 55 + 외부 L자 커버 | MR60BHA2 |

정확한 좌표와 공차는 `설계_사양.txt` 를 따른다.

## 출력 시 주의

- 출력 전 단위(mm)와 실제 센서 보드 치수를 반드시 대조한다.
- 본체는 센서 전면을, 후면 패널은 넓은 평면을 빌드 플레이트에 놓는다.
- 슬라이드 레일이 빡빡하면 XY 보정을 0.1–0.2 적용한다.
- 시험 출력 없이 최종 출력을 진행하지 않는다.

## 관리 규칙

동일 파일명을 덮어쓰지 않고 버전 접미사를 붙인다. 추가 시 설계 버전, 단위,
프린터·재질 조건, 변경 근거를 함께 남긴다. STL 은 재생성하지 않고 원본을 보존한다.

## 출처

SafeNest 팀 자체 설계다. 외부에서 내려받은 모델은 포함하지 않는다.
